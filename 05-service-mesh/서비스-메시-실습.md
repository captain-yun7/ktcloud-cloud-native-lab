# 서비스 메시 — 실습

이 문서는 서비스 메시 과목의 실습 1~6입니다. 아래 목록 순서대로 하면 됩니다. 실습마다 파일이 따로 있습니다.

- 교안에 **실습 안내** 슬라이드가 나오면 이 문서의 해당 실습을 처음부터 끝까지 스스로 진행합니다. 막히면 Discord에 질문합니다([질문하는 법](./실습/00-시작하기-전에.md#5-막히면--질문하는-법)).
- 메시 도구를 두 개 씁니다. 실습 1~3은 **Linkerd**, 실습 4~6은 **Istio**입니다. 같은 일을 하는 두 도구를 직접 비교합니다.
- 실습 1~5의 앱은 Kubernetes·클라우드 보안·CI/CD 과목에서 쓴 **todo**(web → api → db)입니다. 기능을 하나씩 todo에 붙여 봅니다. 실습 6과 미션은 서비스가 11개인 **Online Boutique**(쇼핑몰 예제)로 "서비스가 많을 때 메시가 왜 필요한가"를 봅니다.

**실습 하나는 이렇게 생겼습니다** (앞 과목 실습 문서와 같은 틀)

| 부분 | 내용 |
|---|---|
| **무엇을 하나요** | 이 실습에서 할 일과 왜 하는지 |
| **필요한 것** | 앞 실습에서 만들어 둔 것 |
| **1단계, 2단계 …** | 명령 → **이 명령은**(쉬운 풀이) → **이렇게 나오면 성공**(화면 예) → **이렇게 나오면?**(자주 나는 오류와 해결) |
| **끝났는지 확인** | ☐ 체크리스트. 모두 ☑이면 끝 |
| **정리** | 다음 실습에 방해되지 않게 지울 것, 지우면 안 되는 것 |
| **확인 문제** | 방금 한 명령을 조금 바꿔 보는 문제. 필요한 명령은 모두 그 실습까지 나왔습니다 |

# 클라우드 보안 — 미션

미션은 실습에서 배운 것을 **스스로 조합해** 푸는 과제입니다. 실습처럼 명령을 다 적어 두지 않았습니다. 대신 막히면 펼쳐 볼 수 있는 힌트가 과제마다 있습니다.

- 스스로 풉니다. 막히면 **힌트를 1단계부터 하나씩** 펼쳐 보고(▶ 힌트 글자를 누르면 펼쳐짐), 그래도 막히면 Discord에 질문합니다.
- 미션마다 끝에 **결과 정리 표**가 있습니다. 리뷰 때 함께 보니 채워 두세요.
- 이 과목은 **찾기(점검)와 막기(설정·정책)** 만 다룹니다. 공격 기법은 다루지 않습니다.
- 취약점 개수는 취약점 DB가 바뀔 때마다 달라집니다. 숫자보다 "무엇이 얼마나 줄었는가"를 봅니다.

## 시작하기 전에

실습 문서의 [시작하기 전에](./실습/00-시작하기-전에.md#시작하기-전에)와 같습니다. 핵심만 다시 적습니다.

| 확인할 것 | 내용 |
|---|---|
| 접속 | `ssh ktc-sNN` — [접속 안내](../00-접속-안내.md) |
| 클러스터 | Kubernetes 과목의 `lab` 클러스터를 그대로 씁니다. `kubectl get nodes`가 `lab-control-plane   Ready`인지 확인 |
| 도구 | `trivy --version`이 나오는지. 안 나오면 실습 문서 시작하기 전에 3의 `make tools` |
| 네임스페이스 | 미션 1은 `memo`, 미션 2는 `shop`과 `other`(실습 1의 시험 파드 `t`). 명령마다 `-n 이름`을 붙입니다(빠뜨리면 `default`에 만들어짐) |
| YAML | 스페이스 2칸, 탭 금지. `nano 파일` → Ctrl+O → Enter → Ctrl+X |
| 오류가 나면 | `kubectl get pods -n …` → `kubectl describe pod -n … <이름>`의 Events → `kubectl get events -n …` → `kubectl logs -n … <이름>` |
| 질문 | 에러 첫 줄을 글자로 복사해 Discord에. 한 일 / 기대 / 실제 / 해 본 것 |

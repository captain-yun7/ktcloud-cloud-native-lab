# 클라우드 보안 — 실습

이 문서는 클라우드 보안 과목의 실습 1~10입니다. Kubernetes 과목처럼 처음 해 보는 분도 혼자 끝까지 따라올 수 있게 한 단계씩 적었습니다. 아래 목록 순서대로 하면 됩니다. 실습마다 파일이 따로 있습니다.

- 교안에 **실습 안내** 슬라이드가 나오면 이 문서의 해당 실습을 처음부터 끝까지 스스로 진행합니다. 막히면 Discord에 질문합니다([질문하는 법](./실습/00-시작하기-전에.md#6-막히면--질문하는-법)).
- 실습 앱은 **Kubernetes 실습 7에서 직접 띄운 할 일 앱 todo**(화면 web · API api · DB db)입니다. 이번에는 네임스페이스 `todo`에 `securityContext`·NetworkPolicy·RBAC 같은 설정을 하나도 넣지 않고 띄워 두고, root로 도는 api · 다른 네임스페이스에서 열리는 db · 파드 안 토큰 같은 빈틈을 찾은 뒤 하나씩 막습니다. 앱은 이미 아니까 막는 설정에만 집중하면 됩니다.
- Online Boutique(쇼핑몰 예제, `shop`)는 미션 2에서만 씁니다.
- 이 과목은 **찾기(점검)와 막기(설정·정책)** 만 다룹니다. 해킹 도구나 공격 기법은 다루지 않습니다. 열린 설정으로 데이터가 읽히고 지워지는 장면은 실습 1 5단계에서 직접 해 봅니다(일반 명령 kubectl · psql만 씀).
- 취약점 개수는 **취약점 DB가 갱신될 때마다 바뀝니다.** 숫자가 문서와 조금 달라도 괜찮습니다. "어느 쪽이 더 적은가"를 봅니다.

**실습 하나는 이렇게 생겼습니다** (Kubernetes 실습 문서와 같은 틀)

| 부분 | 내용 |
|---|---|
| **무엇을 하나요** | 이 실습에서 할 일과 왜 하는지 |
| **필요한 것** | 앞 실습에서 만들어 둔 것 |
| **1단계, 2단계 …** | 명령 → **이 명령은**(쉬운 풀이) → **이렇게 나오면 성공**(화면 예) → **이렇게 나오면?**(자주 나는 오류와 해결) |
| **끝났는지 확인** | ☐ 체크리스트. 모두 ☑이면 끝 |
| **정리** | 다음 실습에 방해되지 않게 지울 것, 지우면 안 되는 것 |
| **확인 문제** | 방금 한 명령을 조금 바꿔 보는 문제. 필요한 명령은 모두 그 실습까지 나왔습니다 |

# 모니터링 — 실습

이 문서는 모니터링 과목의 실습 1~8입니다. 처음 해 보는 분도 혼자 끝까지 따라올 수 있게 한 단계씩 적었습니다. 아래 목록 순서대로 하면 됩니다. 실습마다 파일이 따로 있습니다.

- 교안에 **실습 안내** 슬라이드가 나오면 이 문서의 해당 실습을 처음부터 끝까지 스스로 진행합니다. 막히면 Discord에 질문합니다([질문하는 법](./실습/00-시작하기-전에.md#4-막히면--질문하는-법)).
- 클러스터는 **서비스 메시 과목에서 쓰던 것 그대로**입니다. 노드 3개 클러스터에 Istio가 있고, 네임스페이스 `shop`에 Online Boutique(쇼핑몰 예제)가 사이드카와 함께 떠 있습니다.
- 앱을 둘 씁니다. 기능 하나씩(PromQL·내 앱 지표·대시보드·로그)은 서비스가 셋인 **todo**로, 서비스가 많을 때의 관측(골든 시그널·트레이스·경보·장애 찾기)은 **Online Boutique**로 합니다.
- 과목의 끝은 **장애를 지표 → 로그 → 트레이스로 찾는 것**(미션 2)입니다. 프로젝트의 대시보드 설계·알림 기준·장애 보고서에 그대로 씁니다.

**실습 하나는 이렇게 생겼습니다** (앞 과목 실습 문서와 같은 틀)

| 부분 | 내용 |
|---|---|
| **무엇을 하나요** | 이 실습에서 할 일과 왜 하는지 |
| **필요한 것** | 앞 실습에서 만들어 둔 것 |
| **1단계, 2단계 …** | 명령 → **이 명령은**(쉬운 풀이) → **이렇게 나오면 성공**(화면 예) → **이렇게 나오면?**(자주 나는 오류와 해결) |
| **끝났는지 확인** | ☐ 체크리스트. 모두 ☑이면 끝 |
| **정리** | 다음 실습에 방해되지 않게 지울 것, 지우면 안 되는 것 |
| **확인 문제** | 방금 한 것을 조금 바꿔 보는 문제. 필요한 명령은 모두 그 실습까지 나왔습니다 |

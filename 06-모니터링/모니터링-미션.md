# 모니터링 — 미션

미션은 실습에서 배운 것을 **스스로 조합해** 푸는 과제입니다. 실습처럼 명령을 다 적어 두지 않았습니다. 대신 막히면 펼쳐 볼 수 있는 힌트가 있습니다.

- 스스로 풉니다. 막히면 **힌트를 1부터 하나씩** 펼쳐 보고(▶ 힌트 글자를 누르면 펼쳐짐), 그래도 막히면 Discord에 질문합니다.
- 미션마다 끝에 **결과 정리 표**가 있습니다. 리뷰 때 함께 보니 채워 두세요.
- 두 미션 모두 쇼핑몰 **Online Boutique**(`shop`)입니다. 서비스가 11개일 때 어디가 나쁜지 찾는 연습입니다.

| 미션 | 언제 하나 | 무엇을 |
|---|---|---|
| [미션 1. shop 골든 시그널 대시보드](./미션/01-shop-골든-시그널-대시보드.md) | 교안 05장(실습 5)까지 마친 뒤 | Istio 사이드카 지표로 서비스별 요청 수·오류·지연 대시보드 |
| [미션 2. 장애 찾기 — 지표 · 로그 · 트레이스](./미션/02-장애-찾기-지표-로그-트레이스.md) | 교안 08장(실습 8)까지 마친 뒤 | 쇼핑몰에 생긴 장애 하나를 지표 → 로그 → 트레이스로 찾고 짧은 장애 보고 쓰기 |

## 시작하기 전에

실습 문서의 [시작하기 전에](./실습/00-시작하기-전에.md)와 같은 클러스터·브라우저 화면을 씁니다.

| 확인할 것 | 내용 |
|---|---|
| 접속 | `ssh ktc-sNN` — [접속 안내](../00-접속-안내.md) |
| 쇼핑몰 | `kubectl -n shop get pods` — 12개 모두 `2/2 Running` |
| 화면 | Grafana(`grafana.localhost:<포트>`)의 Explore — 데이터 소스 Prometheus · Loki · Tempo |
| 장애를 낸 뒤 | 미션 1의 장애는 **꼭 되돌립니다**(`--replicas=1`). 다음 실습·과목에 영향을 줍니다 |
| 질문 | 오류 첫 줄을 글자로 복사해 Discord에. 한 일 / 기대 / 실제 / 해 본 것 |

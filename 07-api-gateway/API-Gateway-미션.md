# API Gateway — 미션

미션은 실습에서 배운 것을 **스스로 조합해** 푸는 과제입니다. 실습처럼 명령을 다 적어 두지 않았습니다. 대신 막히면 펼쳐 볼 수 있는 힌트가 있습니다.

- 스스로 풉니다. 막히면 **힌트를 1부터 하나씩** 펼쳐 보고(▶ 힌트 글자를 누르면 펼쳐짐), 그래도 막히면 Discord에 질문합니다.
- 미션 끝에 **결과 정리 표**가 있습니다. 리뷰 때 함께 보니 채워 두세요.
- 대상은 쇼핑몰 **Online Boutique**(`shop`)입니다. 실습의 todo에서 한 경로 나누기 · 키 · 속도 제한 · HTTPS를 서비스가 11개인 쇼핑몰 앞문에 조합합니다.

| 미션 | 언제 하나 | 무엇을 |
|---|---|---|
| [미션. Online Boutique 앞문](./미션/01-Online-Boutique-앞문.md) | 교안 07장(실습 8)까지 마친 뒤 | `shop.localhost:8080` 손님 입구 + 파트너 경로(`/partner`)에만 키와 파트너별 속도 제한 + 쇼핑몰 입구 HTTPS |

## 시작하기 전에

실습 문서의 [시작하기 전에](./실습/00-시작하기-전에.md)와 같은 클러스터·입구를 씁니다.

| 확인할 것 | 내용 |
|---|---|
| 접속 | `ssh ktc-sNN` — [접속 안내](../00-접속-안내.md) |
| 입구 | `kubectl -n gateway get gateway front` — `PROGRAMMED` `True`(실습 1) |
| 쇼핑몰 | `kubectl -n shop get pods` — 12개 모두 `2/2 Running` |
| 파일 | 실습에서 쓴 `~/apigw`의 YAML을 복사해 고쳐 씁니다. 인증서는 실습 8의 `~/apigw/tls` |
| HTTPS | `curl --cacert ~/apigw/tls/ca.crt https://todo.localhost:8443/` → `200`(실습 8의 8443 잇기가 떠 있음). 안 되면 실습 8 3단계 나의 첫 세 줄 |
| 장애를 낸 뒤 | 도전 B의 지연은 **꼭 되돌립니다**(`EXTRA_LATENCY-`) |
| 질문 | 오류 첫 줄을 글자로 복사해 Discord에. 한 일 / 기대 / 실제 / 해 본 것 |

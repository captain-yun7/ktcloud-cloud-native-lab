# kt cloud TECH UP 클라우드 네이티브 — 실습 자료

수업에서 쓰는 실습 문서와 오후 미션을 올리는 저장소입니다. 자료는 **그날 아침** 올라옵니다.

## 처음 한 번
1. [실습 서버 접속 안내](./00-접속-안내.md)대로 본인 VM에 접속합니다
2. VM에서 이 저장소를 받습니다
   ```bash
   git clone https://github.com/captain-yun7/ktcloud-cloud-native-lab.git
   ```
3. 새 자료가 올라오면
   ```bash
   cd ~/ktcloud-cloud-native-lab && git pull
   ```

## 하루 진행
| 시간 | 방식 | 자료 |
|---|---|---|
| 오전 | 강사 설명 → 검은 바탕 **"따라 하기"** 슬라이드가 나오면 같이 입력 | `MM-DD-오전-실습.md` |
| 오후 | **미션** — 스스로 풉니다. 막히면 힌트를 1단계부터 하나씩 펼칩니다 | `MM-DD-오후-미션.md` |
| 마지막 | 리뷰 — 정답 시연, 막힌 곳 공유 | 수업 화면 |

미션 문서 맨 아래의 **제출 표**를 채워 제출합니다(제출 방법은 수업에서 안내).

# Kubernetes — 미션

미션은 실습에서 배운 것을 **스스로 조합해** 푸는 과제입니다. 실습처럼 명령을 다 적어 두지 않았습니다. 대신 막히면 펼쳐 볼 수 있는 힌트가 단계별로 있습니다.

- 스스로 풉니다. 막히면 **힌트를 1단계부터 하나씩** 펼쳐 보고(▶ 힌트 글자를 누르면 펼쳐짐), 그래도 막히면 Discord에 질문합니다.
- 미션마다 끝에 **결과 정리 표**가 있습니다. 리뷰 때 함께 보니 채워 두세요.
- 문서에 적힌 시간·메모리 수치는 강사 VM에서 단독으로 측정한 값이라 여러분의 결과와 조금 다를 수 있습니다.

## 시작하기 전에

실습 문서의 [시작하기 전에](./실습/00-시작하기-전에.md#시작하기-전에)와 같습니다. 핵심만 다시 적습니다.

| 확인할 것 | 내용 |
|---|---|
| 접속 | `ssh ktc-sNN` — [접속 안내](../00-접속-안내.md) |
| 클러스터 | `kubectl get nodes`가 `lab-control-plane   Ready`. 아니면 [실습 문서 시작하기 전에 6](./실습/00-시작하기-전에.md#6-클러스터가-떠-있는지-확인-실습-2부터-매번) |
| YAML | 스페이스 2칸, 탭 금지. `nano 파일` → Ctrl+O → Enter → Ctrl+X. 꼬이면 `rm 파일` 후 다시 |
| 네임스페이스 | 미션은 실습과 섞이지 않게 **따로 만든 네임스페이스**에서 합니다. 명령마다 `-n 이름`을 붙입니다(빠뜨리면 `default`에 만들어짐) |
| 브라우저로 보기 | 터미널 1에서 `kubectl port-forward -n <네임스페이스> svc/frontend 8090:80` → VS Code **PORTS** 탭에서 `8090` 전달 → `http://localhost:8090`. VM 8080은 kind가 쓰므로 8090을 씁니다 |
| 오류가 나면 | `kubectl get pods -n …` → `kubectl describe pod -n … <이름>`의 Events → `kubectl logs -n … <이름>`. [자주 만나는 오류 한눈에](./실습/99-자주-쓴-명령과-오류.md#자주-만나는-오류-한눈에) |
| 질문 | 에러 첫 줄을 글자로 복사해 Discord에. 한 일 / 기대 / 실제 / 해 본 것 |

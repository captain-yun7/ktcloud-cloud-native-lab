# Kubernetes — 실습

이 문서는 Kubernetes 과목의 실습 1~12입니다. Docker 과목처럼 처음 해 보는 분도 혼자 끝까지 따라올 수 있게 한 단계씩 적었습니다. 아래 목록 순서대로 하면 됩니다. 실습마다 파일이 따로 있습니다.

- 교안에 **실습 안내** 슬라이드가 나오면 이 문서의 해당 실습을 처음부터 끝까지 스스로 진행합니다. 막히면 Discord에 질문합니다([질문하는 법](./실습/00-시작하기-전에.md#10-막히면--질문하는-법)).
- 실습 앱은 **Docker 과목에서 만든 Node 앱 그대로**입니다. `hello`(인사말 한 줄, `hello:v1`·`hello:v2` 이미지)와 `todo`(화면 web · API api · DB db 세 개)를 쿠버네티스에 올립니다. 앱은 이미 아니까 쿠버네티스가 하는 일에만 집중하면 됩니다.
- Online Boutique(쇼핑몰 예제)는 미션과 실습 12(Helm)에서만 씁니다.

**실습 하나는 이렇게 생겼습니다** (Docker 실습 문서와 같은 틀)

| 부분 | 내용 |
|---|---|
| **무엇을 하나요** | 이 실습에서 할 일과 왜 하는지 |
| **필요한 것** | 앞 실습에서 만들어 둔 것 |
| **1단계, 2단계 …** | 명령 → **이 명령은**(쉬운 풀이) → **이렇게 나오면 성공**(화면 예) → **이렇게 나오면?**(자주 나는 오류와 해결) |
| **끝났는지 확인** | ☐ 체크리스트. 모두 ☑이면 끝 |
| **정리** | 다음 실습에 방해되지 않게 지울 것, 지우면 안 되는 것 |
| **확인 문제** | 방금 한 명령을 조금 바꿔 보는 문제. 필요한 명령은 모두 그 실습까지 나왔습니다 |

# 부록 B3. todo + Online Boutique를 AWS VPC에 올린다면

> 부록 — 본편(D-30) 밖, 클라우드(AWS) 이름으로 더 보고 싶을 때 보는 문서입니다.

지금 VM의 kind 클러스터에서 도는 **todo**(web · api · db)와 **Online Boutique**(서비스 11개 + 장바구니 redis)를 AWS로 옮긴다고 하고 **네트워크 설계도**를 만듭니다. 실제로 AWS에 만들지는 않습니다. 명령은 겹침 검사(실습 3 1단계) 하나뿐입니다. 장애를 넣은 사내망을 고치는 것은 [미션 1](../미션/01-네트워크-장애-해결.md)입니다.

| 조건 | |
|---|---|
| VPC | `10.20.0.0/16` |
| 가용 영역(AZ) | 2개 (a, c) |
| 서브넷 | AZ마다 3층: **퍼블릭**(로드밸런서 · NAT 게이트웨이) / **프라이빗-앱**(쿠버네티스 노드 — 파드가 많음) / **프라이빗-DB**(todo의 DB, 장바구니 캐시) |
| 입구 | 로드밸런서 하나 → 앱 노드의 입구 포트(실습 2의 `30080` 같은 자리) → todo · 쇼핑몰 |
| 겹치면 안 되는 대역 | 실습 서버 망 `10.10.0.0/16`(나중에 이 망과 이을 수 있게), 쿠버네티스 Service `10.96.0.0/12`(실습 2에서 본 값) |

## 과제 1. 서브넷 표와 겹침 검사

서브넷 6개(AZ 2 × 3층)의 **이름 · AZ · CIDR · 주소 수 · 둘 것**을 정하고, 실습 3 1단계의 `ipaddress` 코드로 **VPC 안에 있는지, 서로 겹치지 않는지, 겹치면 안 되는 대역과 안 겹치는지** 검사합니다.

<details><summary>힌트 1</summary>

앱 서브넷은 파드가 많으므로 크게(`/20` = 4,096개), 나머지는 `/24`. 칸 사이를 조금 비워 두면 나중에 늘리기 쉽습니다. `/20`의 시작은 셋째 숫자가 16의 배수(0 · 16 · 32 · 48 …)여야 합니다.
</details>

<details><summary>힌트 2</summary>

`ip.ip_network("10.20.1.0/24").subnet_of(vpc)` = VPC 안에 있으면 `True`. 서로 겹침은 실습 3의 `overlaps`. 두 개씩 모두 비교하려면:

```python
from itertools import combinations
for (a, x), (b, y) in combinations(nets.items(), 2):
    if x.overlaps(y): print("겹침:", a, b)
```
</details>

**이렇게 나오면 성공**: 서브넷마다 `VPC 안: True`, 겹침 줄이 없음, 마지막에 `통과`(또는 직접 정한 "문제 없음" 표시).

## 과제 2. 네트워크 구성도

인터넷 → 로드밸런서 → 앱 → DB, 그리고 NAT 게이트웨이의 위치를 그립니다. 두 AZ, 퍼블릭/프라이빗 칸, 서브넷마다 라우팅 표의 `0.0.0.0/0` 줄이 어디를 가리키는지도 적습니다. 손그림 사진도 됩니다.

<details><summary>힌트</summary>

로드밸런서·NAT 게이트웨이 = 퍼블릭, 앱·DB = 프라이빗. 앱이 밖으로 나갈 때(이미지 받기 등)는 NAT 게이트웨이를 거칩니다(실습 3 5단계). 로드밸런서는 두 AZ의 퍼블릭 칸에 걸쳐 하나입니다.
</details>

## 과제 3. AZ-a 전체 장애

AZ-a 전체가 멈추면 로드밸런서 · 앱(todo, 쇼핑몰) · todo DB · 장바구니 캐시 · NAT 게이트웨이는 각각 어떻게 되나요? NAT 게이트웨이를 AZ마다 하나씩 두는 이유도 적습니다.

<details><summary>힌트</summary>

실습 5의 "한 AZ가 멈추면 → 헬스 체크로 20/20"을 떠올립니다. 로드밸런서는 헬스 체크로 멈춘 쪽을 뺍니다. 앱이 밖으로 나갈 때 쓰는 NAT가 AZ-a에만 있다면?
</details>

## 과제 4. 보안그룹 표

로드밸런서 · 앱 노드 · todo DB · 장바구니 캐시에 붙일 보안그룹 4개를 정합니다. 칸마다 **들어오는 것 허용**(프로토콜 · 포트 · 출발지)을 적습니다. 포트: todo DB `5432`, 장바구니 캐시 `6379`, 앱 노드의 입구 `30080`, 로드밸런서 `80`·`443`.

<details><summary>힌트</summary>

실습 4의 보안그룹 줄(`-p tcp --dport 5432 -s 10.0.1.0/24`)과 같은 모양입니다. AWS 보안그룹은 출발지에 주소 대신 **다른 보안그룹 이름**을 적을 수 있습니다 — "앱 보안그룹이 붙은 것에서 오는 5432만". 답은 자동 허용이므로(실습 4 2단계) 답 규칙은 적지 않습니다.
</details>

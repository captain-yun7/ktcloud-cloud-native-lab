# 클라우드 네트워킹 — 미션

미션은 실습에서 배운 것을 **스스로 조합해** 푸는 과제입니다. 실습처럼 명령을 다 적어 두지 않았습니다. 대신 막히면 펼쳐 볼 수 있는 힌트가 있습니다.

- 스스로 풉니다. 미션 문서의 **층별 점검표**를 1번부터 차례로 쳐 보고 정상 출력과 비교합니다. 그래도 막히면 Discord에 질문합니다.
- 미션 끝에 **결과 정리 표**가 있습니다. 리뷰 때 함께 보니 채워 두세요.
- 이 과목의 미션은 **고치기** 하나입니다. 실습 3·4에서 VM 안에 만든 사내망에 스크립트가 고장을 섞어 넣고, 여러분이 DNS → 라우팅 → 포트 → 방화벽 → 앱 순서로 찾아 고칩니다. 클라우드 계정은 쓰지 않습니다.

| 미션 | 언제 하나 | 무엇을 |
|---|---|---|
| [미션 1. 네트워크 장애 해결](./미션/01-네트워크-장애-해결.md) | 실습 4까지 마친 뒤 | 과제 1~3: 고장 만들고 증상 보기 · 층별 점검표로 찾아 고치기(DNS → 라우팅 → 포트 → 방화벽 → 앱) · 결과 정리 |

## 시작하기 전에

실습 문서의 [시작하기 전에](./실습/00-시작하기-전에.md)와 같습니다. 핵심만 다시 적습니다.

| 확인할 것 | 내용 |
|---|---|
| 접속 | `ssh ktc-sNN` — [접속 안내](../00-접속-안내.md) |
| 미션 1 | `sudo bash ~/ktcloud-cloud-native-lab/lab/network/break-vpc.sh`로 장애를 넣은 사내망을 만들고 `bash vpc-check.sh`로 확인. 새 터미널이면 줄임말 `alias web=… db=… rt=…` |
| 끝나면 | `sudo bash ~/ktcloud-cloud-native-lab/lab/network/vpc-down.sh`(클러스터는 그대로) |
| 질문 | 오류 첫 줄을 글자로 복사해 Discord에. 한 일 / 기대 / 실제 / 해 본 것 |

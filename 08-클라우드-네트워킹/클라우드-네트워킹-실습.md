# 클라우드 네트워킹 — 실습

이 문서는 클라우드 네트워킹 과목의 실습 1~4입니다. 클라우드를 직접 다루기 전에 온프레미스 사내망의 기초를 클라우드 계정 없이 해 봅니다. 웹 요청의 DNS · TCP · TLS · HTTP를 명령으로 하나씩 확인하고(실습 1), **지금까지 쓴 서버 VM과 클러스터**의 IP 주소와 경로(서브넷 · 게이트웨이 · 라우팅)를 확인하고(실습 2), VM 안에 **네트워크 네임스페이스**로 사내망을 구성해 리눅스로 라우터 · NAT · 방화벽을 직접 설정합니다(실습 3·4). 클라우드(AWS)에서 부르는 이름은 실습마다 끝의 "클라우드에서는"과 교안 05장 대응표에서 봅니다. 아래 목록 순서대로 하면 됩니다. 실습마다 파일이 따로 있습니다.

- 교안에 **실습 안내** 슬라이드가 나오면 이 문서의 해당 실습을 처음부터 끝까지 스스로 진행합니다. 막히면 Discord에 질문합니다([질문하는 법](./실습/00-시작하기-전에.md#4-막히면--질문하는-법)).
- 실습 1·2는 VM과 클러스터를 **읽기만** 합니다. 실습 3·4는 클러스터를 건드리지 않고, 끝나면 `vpc-down.sh`로 지웁니다.
- 앞 과목과 이어집니다: Docker의 **포트 연결**, Kubernetes의 **파드 IP · Service · Ingress**, 클라우드 보안의 **NetworkPolicy**, API Gateway의 **8080 입구와 HTTPS**가 여기서 네트워크 기초(주소 · 라우팅 · 포트 · 방화벽)와 이어집니다.

**실습 하나는 이렇게 생겼습니다** (앞 과목 실습 문서와 같은 틀)

| 부분 | 내용 |
|---|---|
| **무엇을 하나요** | 이 실습에서 할 일과 왜 하는지 |
| **필요한 것** | 앞 실습에서 만들어 둔 것 |
| **1단계, 2단계 …** | 명령 → **이 명령은**(쉬운 풀이) → **이렇게 나오면 성공**(화면 예) → **이렇게 나오면?**(자주 나는 오류와 해결) |
| **끝났는지 확인** | ☐ 체크리스트. 모두 ☑이면 끝 |
| **정리** | 다음 실습에 방해되지 않게 지울 것, 지우면 안 되는 것 |
| **클라우드에서는** | 이 실습에서 한 것을 클라우드(AWS)에서 부르는 이름 몇 줄(실습 3·4) |
| **확인 문제** | 방금 한 명령을 조금 바꿔 보는 문제 |

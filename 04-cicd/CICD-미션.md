# CI/CD — 미션

미션은 실습에서 배운 것을 **스스로 조합해** 푸는 과제입니다. 실습처럼 명령을 다 적어 두지 않았습니다. 대신 막히면 펼쳐 볼 수 있는 힌트가 단계별로 있습니다.

- 스스로 풉니다. 막히면 **힌트를 1부터 하나씩** 펼쳐 보고(▶ 힌트 글자를 누르면 펼쳐짐), 그래도 막히면 Discord에 질문합니다.
- 미션마다 끝에 **결과 정리 표**가 있습니다. 리뷰 때 함께 보니 채워 두세요.
- 실습에서 키워 온 내 저장소 `cicd-lab`을 그대로 씁니다. 두 미션 모두 todo 앱입니다.
- 실행 시간은 GitHub 러너·VM 상황에 따라 달라집니다. 문서의 시간은 강사가 측정한 값입니다.

## 시작하기 전에

실습 문서의 [시작하기 전에](./실습/00-시작하기-전에.md)와 같습니다. 핵심만 다시 적습니다.

| 확인할 것 | 내용 |
|---|---|
| 접속 | `ssh ktc-sNN` — [접속 안내](../00-접속-안내.md) |
| 내 저장소 | `cd ~/cicd-lab && git pull` — 실습에서 키운 저장소에서 시작 |
| 실행 보기 | `gh run watch` 또는 브라우저의 **Actions** 탭 |
| 파이프라인이 빨간 X | Actions 탭에서 빨간 단계를 눌러 로그의 **마지막 줄**부터 봅니다 |
| 질문 | 오류 첫 줄을 글자로 복사해 Discord에. 한 일 / 기대 / 실제 / 해 본 것 |

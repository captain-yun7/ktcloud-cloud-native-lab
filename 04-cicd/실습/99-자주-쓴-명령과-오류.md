# 자주 쓴 명령과 오류

## 자주 쓴 명령
| 명령 | 하는 일 | 실습 |
|---|---|---|
| `git status` / `git diff` | 무엇이 바뀌었나 | 2 |
| `git add` → `git commit -m` → `git push` | 기록하고 올리기 | 2~ |
| `git switch -c 브랜치` / `git push -u origin 브랜치` | 브랜치 만들고 올리기 | 2, 4 |
| `git pull` (`--rebase`) | GitHub의 새 커밋 받기 | 2, 5, 7 |
| `git revert --no-edit HEAD` / `git revert -m 1 <병합 커밋>` | 지난 커밋 / 병합 커밋을 되돌리는 커밋 | 3, 7, 미션 2 |
| `gh run list` / `gh run watch` | 워크플로 실행 목록 / 지켜보기 | 3~4, 미션 1 |
| `gh pr create` / `gh pr close -d` | PR 열기 / 닫고 브랜치 지우기 | 4, 미션 1 |
| `docker pull ghcr.io/<아이디>/cicd-lab/api:main` | 파이프라인이 올린 이미지 받기 | 3 |
| `trivy image --exit-code 1 --severity CRITICAL --ignore-unfixed 이미지; echo $?` | 게이트와 같은 검사, 종료 코드 보기 | 4 |
| `make jenkins` / `make argocd` | Jenkins · Argo CD 띄우기 | 5, 6 |
| `kustomize edit set image todo-api=…` | 매니페스트의 이미지 태그 바꾸기(Jenkins·Actions가 씀) | 5, 미션 2 |
| `kubectl apply -k deploy/overlays/dev` / `kubectl diff -k …` | 손으로 배포 / Git과 클러스터 차이 | 6 |
| `kubectl -n argocd get app` (`-w`) | Argo CD 앱 상태 | 6, 7 |
| `kubectl -n todo-dev exec deploy/web -- wget -qO- http://api:3000/api/health` | 배포된 api 응답 보기 | 7 |

## 자주 만나는 오류 한눈에
| 오류 | 원인 | 해결 | 실습 |
|---|---|---|---|
| `Author identity unknown ... Please tell me who you are.` | git 이름·이메일 설정 안 함 | `git config --global user.name`·`user.email` | 1 |
| `gh: command not found` | 도구 설치 뒤 셸을 새로 읽지 않음 | `source ~/.bashrc` | 1 |
| `Username for 'https://github.com':` | `gh auth setup-git` 안 함 | Ctrl+C → `gh auth setup-git` | 1, 2 |
| `Everything up-to-date`인데 GitHub에 변경 없음 | 커밋 없이 push | `git commit` 뒤 push | 2 |
| `! [rejected] main -> main (fetch first)` | GitHub에 내 VM에 없는 커밋이 있음(Jenkins·봇 커밋) | `git pull --rebase` 뒤 push | 2, 5, 7 |
| 편집기(vi)가 열려 나올 수 없음 | `git commit`에 `-m` 빠뜨림 | `Esc` → `:q!` → Enter, `-m` 붙여 다시 | 2 |
| 새 파일이 커밋에 안 들어감 | `-a`는 이미 기록된 파일만 넣음 | `git add 파일` 먼저 | 2, 3 |
| `refusing to allow an OAuth App to create or update workflow ... without workflow scope` | 토큰에 `workflow` 권한 없음 | 토큰 새로 만들어 `gh auth login --with-token` | 3 |
| Actions 탭에 아무것도 안 뜸 | 폴더 이름 오타 또는 YAML 들여쓰기 오류 | `ls .github/workflows`, Actions 탭의 빨간 경고, 공백 2칸·탭 금지 | 3 |
| `found no in progress runs to watch` | push 직후라 실행이 아직 없음 | 몇 초 뒤 `gh run watch` 다시 | 3 |
| `docker pull ghcr.io/…`에서 `error from registry: denied` | 아직 올리지 않았거나 주소 오타 — 없는 패키지에도 `denied`로 답함 | 실행이 초록인지, 주소(소문자·`cicd-lab`) 확인 | 3 |
| `invalid reference format: repository name (…) must be lowercase` | 주소에 대문자 | 모두 소문자로 | 3 |
| PR을 원래대로 되돌렸더니 실행이 안 생김 | PR 변경이 0줄 → `paths` 조건에 안 걸림 | 고칠 때는 줄을 더해서(예: `RUN apk upgrade --no-cache`) | 4 |
| test에서 `host not found in upstream "api"` | nginx 설정 검사에 `--add-host api:127.0.0.1` 빠짐 | 미션 1 힌트 2 | 미션 1 |
| Jenkins 빌드가 몇 초 만에 `ERROR: github` | 자격 증명 `github`이 없거나 ID 오타 | Credentials에 ID `github`로 추가 | 5 |
| Jenkins `올리기`에서 `denied` | 토큰에 `write:packages` 없음 | 토큰 다시 만들고 자격 증명 바꾸기 | 5 |
| Jenkins에 누르지 않은 빌드가 `NOT_BUILT` | 폴링이 api가 안 바뀐 커밋(매니페스트 커밋)을 봄 → `when`이 건너뜀 | 정상 | 5, 7 |
| `namespaces "todo-dev" not found` | `apply -k` 전에 네임스페이스를 안 만듦 | `kubectl create namespace todo-dev` | 6 |
| `argocd.localhost`가 안 열림 · `404 page not found` | `make ingress` 빠뜨림, 80이 아닌 포트 포워딩, `localhost`로 엶 | `make ingress`, PORTS에서 80, 주소 `argocd.localhost` | 6 |
| Argo CD 앱이 `Synced`가 안 됨 | `repoURL`의 `<아이디>` 그대로 또는 저장소가 Public 아님 | 파일 고쳐 다시 apply | 6 |
| Git을 바꿨는데 Argo CD가 그대로 | 약 3분마다 확인 | 앱 화면 **REFRESH** | 7, 미션 2 |
| `wget: can't connect to remote host: Connection refused` (web 안에서 `localhost`) | alpine의 `localhost`는 IPv6, nginx는 IPv4만 | `http://127.0.0.1/` | 미션 2 |
| `error: commit … is a merge but no -m option was given.` | 병합 커밋 revert | `git revert -m 1 --no-edit <커밋>` | 미션 2 |

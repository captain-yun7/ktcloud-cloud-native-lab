# CI/CD — 실습

이 문서는 CI/CD 과목의 실습 1~7입니다. Git을 처음 써 보는 분도 혼자 끝까지 따라올 수 있게 한 단계씩 적었습니다. 아래 목록 순서대로 하면 됩니다. 실습마다 파일이 따로 있습니다.

- 교안에 **실습 안내** 슬라이드가 나오면 이 문서의 해당 실습을 처음부터 끝까지 스스로 진행합니다. 막히면 Discord에 질문합니다([질문하는 법](./실습/00-시작하기-전에.md#6-막히면--질문하는-법)).
- 과목 내내 **내 GitHub 저장소 하나(`cicd-lab`)** 를 계속 키워 갑니다. 안에는 Docker·Kubernetes·클라우드 보안 과목에서 쓴 **todo 앱**(api · web · db)과 배포용 매니페스트가 들어 있습니다.
- 앞 과목에서 손으로 한 일(Docker의 이미지 빌드·올리기, 보안의 Trivy 스캔, Kubernetes의 배포)을 이 과목에서는 **push 한 번에 자동으로** 돌게 만듭니다.
- 파이프라인이 도는 시간은 GitHub 러너·VM 상황에 따라 달라집니다.

**실습 하나는 이렇게 생겼습니다** (Docker·Kubernetes·클라우드 보안 실습 문서와 같은 틀)

| 부분 | 내용 |
|---|---|
| **무엇을 하나요** | 이 실습에서 할 일과 왜 하는지 |
| **필요한 것** | 앞 실습에서 만들어 둔 것 |
| **1단계, 2단계 …** | 명령 → **이 명령은**(쉬운 풀이) → **이렇게 나오면 성공**(화면 예) → **이렇게 나오면?**(자주 나는 오류와 해결) |
| **끝났는지 확인** | ☐ 체크리스트. 모두 ☑이면 끝 |
| **정리** | 다음 실습에 방해되지 않게 지울 것, 지우면 안 되는 것 |
| **확인 문제** | 방금 한 명령을 조금 바꿔 보는 문제. 필요한 명령은 모두 그 실습까지 나왔습니다 |
